# Yashwin Gowda K — Developer Portfolio

Responsive 3D-inspired portfolio built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a modern browser.

## Deploy with GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select `main` and `/ (root)`, then Save.
4. The target URL is https://yashwin18.github.io/Portfolio/ after Pages publishes.
